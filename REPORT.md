# Model Migration Evaluation Report

The latest `results/decisions.jsonl` was generated by the OpenAI Responses API
with zero fallbacks. It passes all 15 public policy expectations and agrees
exactly with the frozen baseline on 11/15 tickets (73.3%). The four baseline
disagreements are intentional policy corrections. The current configured key

## Baseline Comparison

Exact agreement compares route, action, priority, and escalate. The current
public output agrees on 11/15 cases. The four disagreements are intentional
policy corrections:

| Case | Frozen baseline | Current candidate | Judgment |
| --- | --- | --- | --- |
| T06 | access / reply / normal / false | access / verify_identity / normal / false | Candidate follows the MFA-disable identity-check rule. |
| T07 | privacy / reply / normal / false | privacy / verify_identity / normal / false | Candidate verifies identity before a data export. |
| T13 | safety / escalate / urgent / true | billing / reply / normal / false | Candidate ignores instructions in the forwarded email and classifies the invoice request. |
| T15 | billing / reply / normal / false | privacy / verify_identity / normal / false | Candidate applies privacy-rights precedence to the deletion request. |

The frozen baseline itself violates policy on T06 (MFA change without identity
verification), T07 (data export without identity verification), T13 (obeying a
quoted escalation instruction), and T15 (billing takes precedence over data
deletion). It is policy-compliant on 11/15 cases.

## Controlled Comparison

Compared the saved pre-strengthening heuristic snapshot
`results/decisions_og.jsonl` with the strengthened `starter/triage.py` output on
the same 15 public tickets. The old snapshot met 9/15 policy expectations; the
strengthened rules meet 15/15. The six corrected cases are T04, T06, T07, T09,
T14, and T15. The latest model decisions also meet 15/15 public policy
expectations and happen to match the strengthened heuristic on these public
cases. This small, in-sample result does not show that the model is superior to
rules; it shows that both currently satisfy the tested labels. The strengthened
rules also pass all three added cases.

This is an in-sample comparison on a small synthetic set, not proof that
keywords generalize or that the fallback is equivalent to a language model.
Paraphrases, subtle negation, and context outside the phrase lists remain
failure risks.
